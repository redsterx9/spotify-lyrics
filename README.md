# Spotify 가사

맥에서 Spotify(또는 음악 앱)로 노래를 틀면, 화면 구석에 가사가 떠서
노래를 따라 한 줄씩 올라갑니다. 클릭은 그대로 통과하므로 하던 일에
방해되지 않습니다.

- 모르는 언어는 **번역**과 **읽는 법(발음)** 을 가사 아래에 함께 보여줍니다
- 글자 색은 **앨범 커버**에서 뽑고, 뒤 화면 밝기에 맞춰 줄마다 알아서 조절됩니다
- 곡이 끝나면 **작사·작곡 크레딧**이 흘러갑니다
- 싱크가 안 맞는 곡은 한 번 맞춰두면 **그 곡에 기억됩니다**

## 받기

[**최신 버전 내려받기**](../../releases/latest) — Releases 에서 zip 을 받으세요.

## 설치

1. 압축을 풀면 **Spotify 가사** 앱 하나가 나옵니다
2. **응용 프로그램** 폴더로 끌어다 놓습니다
3. **오른쪽 클릭 → 열기** 로 한 번 엽니다

파이썬도, 터미널도, 다른 설치도 필요 없습니다. 앱 안에 다 들어 있습니다.

> 첫 실행만 **오른쪽 클릭 → 열기** 로 해주세요. 그냥 더블클릭하면 macOS가
> *"확인되지 않은 개발자"* 라며 막습니다. 한 번만 이렇게 열면 다음부터는
> 더블클릭으로 됩니다.

메뉴 막대에만 사는 앱이라 Dock 에는 안 나옵니다 (설정에서 켤 수 있습니다).
처음 실행하면 안내 화면이 뜨고, 거기서 언어·위치·색·움직임을 골라볼 수 있습니다.

### 처음에 물어보는 권한 두 가지

| 권한 | 왜 필요한가 | 거부하면 |
|---|---|---|
| **Spotify 제어** (자동화) | 지금 재생 중인 곡과 재생 위치를 알아냅니다 | 가사가 아예 안 뜹니다 |
| **화면 기록** | 오버레이 뒤 화면의 밝기를 재서 글자색을 정합니다 | 밝은 배경에서 글자가 안 보일 수 있습니다 |

둘 다 **시스템 설정 → 개인정보 보호 및 보안** 에서 `Spotify 가사` 를 켜주시면 됩니다.

안내 화면 세 번째 페이지에서 그 자리에서 켤 수 있고, 켜지면 초록색으로 바뀝니다.
나중에 꺼지면 메뉴 막대 아이콘이 **⚠︎** 로 바뀌고, 누르면 해당 설정 화면이 바로 열립니다.

## 쓰는 법

메뉴 막대 오른쪽 **♪** 아이콘에서 켜고 끄기, 설정, 둘러보기를 열 수 있습니다.

**♪ 가 안 보인다면** — 아이콘이 많아 자리가 없거나 메뉴 막대가 자동 숨김일 수 있습니다.
설정에서 **Dock에 아이콘 표시**를 켜면 Dock 으로도 열 수 있습니다.

| 명령 | 하는 일 |
|---|---|
| `open -a "Spotify 가사"` | 시작 |
| `"/Applications/Spotify 가사.app/Contents/MacOS/Spotify Lyrics" --settings` | 설정 열기 |
| `… --tutorial` | 둘러보기 다시 보기 |
| `… --on` / `--off` / `--toggle` | 가사 켜기 / 끄기 / 전환 |
| `… --quit` | 종료 |
| `… --doctor` | 가사가 안 뜰 때 원인 진단 |

## 설정

설정 창은 세 개 탭입니다.

- **가사** — 무엇을 보여줄지. 번역, 발음 표기, 내가 아는 언어(45개 중 검색),
  창보다 긴 가사를 어떻게 할지, 곡별 싱크 조정, 크레딧
- **모양** — 어떻게 보일지. 글꼴·크기, 글자 색과 그라데이션, 유리 배경, 움직임
- **일반** — 켜고 끄기, 로그인 시 자동 실행, 어느 앱에서 읽을지,
  어느 화면·어느 모서리에 놓을지, 여백, **모두 기본값으로** 되돌리기

거의 모든 항목 아래에 **실제로 그려지는 예시**가 붙어 있어, 설정을 바꾸면
예시가 그 자리에서 같이 바뀝니다. 오버레이를 보러 갈 필요가 없습니다.

설정은 `~/.config/spotify-lyrics-overlay/config.json` 에 저장됩니다.

### 알아두면 좋은 것

**번역 품질** — 가사 파일에 사람이 만든 번역이 딸려 있고 그게 내 언어면 그걸 그대로 씁니다.
없으면 온라인 번역기를 쓰는데, 한 줄씩 옮기느라 가사에 약합니다.
[Ollama](https://ollama.com) 를 깔고 모델을 하나 받아두면 설정 → 가사 → **번역기** 목록에 뜨고,
곡 전체를 읽고 번역해서 훨씬 자연스럽습니다. 안 깔아도 그냥 됩니다.

**내가 아는 언어** — 여기 체크한 언어로 된 노래에는 번역도 발음도 붙지 않습니다.
한 곡 안에 중국어와 영어가 섞여 있으면 **줄 단위로 판단**해서 영어 줄은 그대로 둡니다.

**싱크는 곡마다 따로 기억합니다** — 한 곡을 맞춰두면 다음에 같은 곡을 틀 때
그대로 적용됩니다. 아무것도 재생 중이 아닐 때 옮기면 기억해 둔 값이 없는
모든 곡의 기본값이 됩니다.

**밝은 배경에서는** 유리 알약이 진한 판으로 바뀝니다. 흰 화면 위의 맑은 유리는
유리로 보이지 않고, 그 위에서 읽히려면 글자가 어두워져야 하는데 그러면 앨범
색이 죽기 때문입니다. 유리의 결을 지키고 싶다면 설정 → 모양 → 유리 배경에서
'그대로 유리' 로 바꾸세요.

**음악 앱** — 설정 → 일반 → 재생 중인 앱 에서 고릅니다. 자동은 지금 재생 중인
쪽을 따라갑니다. 음악 앱은 앨범 커버 주소를 내주지 않아서 그때는 글자 색이
기본 팔레트로 나옵니다.

**모니터가 여러 대라면** 설정 → 일반 → 어느 화면에 에서 고를 수 있습니다.
기본은 메뉴 막대가 있는 화면입니다.

## 가사는 어디서 오나

| 출처 | 쓰임 |
|---|---|
| [lrclib.net](https://lrclib.net) | 기본. 시간이 찍힌 가사 |
| [NetEase Cloud Music](https://music.163.com) | lrclib에 없는 곡, 그리고 크레딧 |
| Google 번역 | 번역 |
| MusicBrainz + AcousticBrainz | 곡의 BPM |

계정이나 API 키가 필요 없고, 곡당 한 번만 불러와 캐시합니다.
밖으로 나가는 것은 **곡 제목과 아티스트뿐**이며 계정이나 식별자는 보내지 않습니다.

**Spotify 공식 API는 가사를 제공하지 않습니다.** Spotify 앱에 보이는 가사는
Musixmatch 것을 비공개 내부 API로 가져오는 것이라 쓰지 않았습니다.

## 안 될 때

**가사가 "가사를 찾는 중..." 에서 멈춰요**
Spotify 제어 권한이 거부돼 있을 수 있습니다.
시스템 설정 → 개인정보 보호 및 보안 → **자동화** 에서 `Spotify 가사` 의 Spotify 를 켜세요.

**"싱크 가사 없음" 이라고 떠요**
그 곡에 시간이 찍힌 가사가 어느 출처에도 없다는 뜻입니다.
평문 가사만 있는 경우 가짜 타이밍으로 넘기지 않고 표시하지 않습니다.

**밝은 배경에서 글자가 잘 안 보여요**
화면 기록 권한이 없으면 배경 밝기를 못 읽습니다. 설정 → 모양 → 글자 색 에
권한을 요청하는 버튼이 나옵니다. 유리 배경을 켜는 것으로도 가려집니다.

**번역이 안 붙어요**
설정 → 가사 를 열어보세요. 온라인 번역기가 요청 한도를 넘겼다면 그렇게 적혀
있고, 잠시 뒤 저절로 회복합니다. 한 번 받아온 번역은 저장해 두므로 같은 곡을
두 번 요청하지 않습니다.

**노트북이 뜨거워져요**
움직이는 그라데이션은 글자를 초당 24번 다시 칠합니다. 설정 → 모양 → 글자 색
에서 선형·방사형만 남기면 CPU 사용량이 크게 떨어집니다. 저전력 모드에서는
저절로 멈춥니다.

**다른 곡의 가사가 나와요**
1.0.1 에서 고쳤습니다. 그래도 겪으신다면 곡 제목과 아티스트를 그대로 알려주세요.

**아무것도 안 될 때**

```
"/Applications/Spotify 가사.app/Contents/MacOS/Spotify Lyrics" --doctor
```

칩·macOS 버전·창 위치·권한·설정을 한 번에 확인해 줍니다. 나오는 내용을 그대로 보내주세요.
기록은 `~/Library/Logs/SpotifyLyrics.log` 에 남습니다.

## 요구 사항

- **macOS 11 이상** — 유리 배경은 **macOS 26 이상**에서만 됩니다 (나머지 기능은 다 동작)
- **Spotify 데스크톱 앱** 또는 **macOS 음악 앱** — 웹 플레이어는 안 됩니다
- Apple 실리콘 / 인텔 둘 다 동작
- 모니터가 여러 대면 메뉴 막대가 있는 화면에 뜹니다 (설정에서 바꿀 수 있습니다)
